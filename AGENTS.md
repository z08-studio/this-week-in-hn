# Repository guidelines

- The publication is **This Week in HN**, part of Weekly Newsletter, maintained by z08 Studio.
- This repository and `z08-studio/hn-newsletter-gen` must remain private and closed source. Do not add an open-source license or change repository visibility.
- Use public Hacker News data for discovery. Do not add public submission forms, contribution invitations, issue templates, or community PR workflows.
- This repository owns issue templates, brand assets, and the reviewed archive. Collection, ranking, and generation belong in the companion generator.
- Keep tracked source, documentation, and newsletter content in English. Do not copy another project's secrets, runtime outputs, branding, or Git history.
- Logo proposals are not approved assets until the user selects one. Preserve the existing Weekly Newsletter, Obsidian, and AI identities.
- No publication weekday or Substack URL has been selected. Do not invent either or inherit another newsletter's schedule.
- Keep unpublished drafts ignored. Publishing an issue and archiving it after publication require a direct user request. No command should publish automatically.
- Use a `bear-` branch for changes and open a draft PR after pushing. Do not push follow-up changes directly to `main`.
